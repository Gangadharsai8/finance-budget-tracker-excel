# 💰 Finance & Budget Tracker (Excel)

An interactive Excel dashboard built to track personal income vs. expenses across categories — designed to give a clear, at-a-glance view of spending habits and budget variance.

## 📌 Project Overview

This project simulates a personal finance tracking system, taking raw income and expense transactions and turning them into a structured budget dashboard. It focuses on formula-driven KPI cards and category-level analysis — practical skills that map directly to real-world financial and business reporting tasks.

## 🎯 Objectives

- Organize income and expense transactions into a clean, analyzable structure
- Build KPI cards summarizing key financial metrics (total income, total expenses, net savings, etc.)
- Identify the top spending category dynamically using lookup formulas
- Analyze budget variance to compare planned vs. actual spending

## 🛠️ Tools & Techniques Used

| Tool / Technique | Purpose |
|---|---|
| INDEX/MATCH | Dynamically identifying the top spending category |
| KPI Cards | Summarizing income, expenses, and net savings at a glance |
| Pivot Cache Management | Resolving conflicts between shared pivot caches for independent views |
| Budget Variance Analysis | Comparing planned vs. actual spend across categories |
| Conditional Formatting | Highlighting over-budget categories for quick visual scanning |

## 📈 What's Inside

- **6 KPI summary cards**, including an INDEX/MATCH-based "Top Spending Category" indicator
- Independent PivotTables with resolved pivot-cache conflicts, so each view filters cleanly without affecting the others
- A budget vs. actual comparison layout to flag overspending by category
- A structured, easy-to-navigate dashboard tab

## 💡 Key Learnings

- How to use INDEX/MATCH for dynamic lookups instead of static values that break when data changes
- Diagnosing and fixing shared pivot-cache issues so multiple PivotTables can filter independently
- Structuring a personal finance dataset so KPI formulas stay accurate as new transactions are added

## 🚀 How to Use

1. Download `budget_tracker_dataset.xlsx` from this repository
2. Open in Excel (2016 or later recommended)
3. Review the KPI dashboard tab for a summary view
4. Explore the PivotTables and budget variance section for category-level detail
